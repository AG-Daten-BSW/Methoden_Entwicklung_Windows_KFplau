## Name
Plau_Kraftfutter

## Übersicht
Dieses Repository dokumentiert ein noch nicht abgeschlossenes Entwicklungsprojekt zur Korrektur von Kraftfutteraufnahmen aus Kraftfutterautomaten und Greenfeeder-Systemen. Ziel war es, verschiedene Methoden zur Datenkorrektur zu testen und insbesondere zu prüfen, ob sich Excel Power Query für diesen Zweck eignet.

Im Verlauf der Arbeiten hat sich gezeigt, dass Power Query bei den anfallenden Datenmengen schnell an seine Leistungsgrenzen stößt und daher keine effiziente Lösung für eine standardisierte Datenkorrektur darstellt. Aus diesem Grund wird perspektivisch eine Weiterentwicklung in Python angestrebt.

Um dennoch zeitnah Daten für den laufenden Versuch M77 aufbereiten zu können, wurden die erprobten Schritte mit Power Query in folgendem Projekt umgesetzt:  [https://gitlab.fdm.fli.de/ag-daten-bs/ag_rinderernaehrung/m77_d1_bis_d6_kali_kraftfutter](https://gitlab.fdm.fli.de/ag-daten-bs/ag_rinderernaehrung/m77_d1_bis_d6_kali_kraftfutter) 


Eine detaillierte Beschreibung der Vorgehensweise finden Sie ebenfalls im Repository: [https://gitlab.fdm.fli.de/ag-daten-bs/ag_rinderernaehrung/m77_d1_bis_d6_kali_kraftfutter/-/blob/master/Durchf%C3%BCrhung_Korrektur_Kraffutteraufnahme_20250815.pdf?ref_type=heads](https://gitlab.fdm.fli.de/ag-daten-bs/ag_rinderernaehrung/m77_d1_bis_d6_kali_kraftfutter/-/blob/master/Durchf%C3%BCrhung_Korrektur_Kraffutteraufnahme_20250815.pdf?ref_type=heads)

## Overview
This repository documents an ongoing development project focused on the correction of concentrate feed intake data from concentrate feeders and Greenfeeder systems. The aim was to test different correction methods and, in particular, to evaluate whether Excel Power Query could be used for this purpose.

During the evaluation, it became clear that Power Query quickly reaches its limits when processing the required amount of data. Therefore, it is not an efficient solution for standardized data correction. As a result, further development in Python is planned.

To ensure timely data processing for the ongoing experiment M77, the tested Power Query workflow was applied in the following project: [https://gitlab.fdm.fli.de/ag-daten-bs/ag_rinderernaehrung/m77_d1_bis_d6_kali_kraftfutter](https://gitlab.fdm.fli.de/ag-daten-bs/ag_rinderernaehrung/m77_d1_bis_d6_kali_kraftfutter) 

A detailed description of the procedure can also be found in the repository:  [https://gitlab.fdm.fli.de/ag-daten-bs/ag_rinderernaehrung/m77_d1_bis_d6_kali_kraftfutter/-/blob/master/Durchf%C3%BCrhung_Korrektur_Kraffutteraufnahme_20250815.pdf?ref_type=heads](https://gitlab.fdm.fli.de/ag-daten-bs/ag_rinderernaehrung/m77_d1_bis_d6_kali_kraftfutter/-/blob/master/Durchf%C3%BCrhung_Korrektur_Kraffutteraufnahme_20250815.pdf?ref_type=heads)
